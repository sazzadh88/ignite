Quick Start

Get up and running in 60 seconds

# Install the CLI
go install github.com/sazzadh88/ignite/cmd/ignite@latest

# Create a new project
ignite new myapp

# Navigate into your project
cd myapp

# Start the development server
ignite serve

Your app is now running at http://localhost:8000

Beautiful, Expressive Code

Ignite brings Laravel's elegance to Go. Here's a taste of what you can build:

Define Routes

package main

import (
    "github.com/sazzadh88/ignite/http"
    "github.com/sazzadh88/ignite/routing"
)

func main() {
    router := routing.New()

    // Simple routes
    router.Get("/users", listUsers)
    router.Post("/users", createUser)

    // Route groups with middleware
    router.Group(func(r *routing.Router) {
        r.Middleware(middleware.Auth())
        r.Get("/dashboard", dashboard)
        r.Resource("/posts", &PostController{})
    })

    http.Serve(":8000", router)
}

Query the Database

package controllers

import (
    "github.com/sazzadh88/ignite/database"
    "github.com/sazzadh88/ignite/http"
)

func listUsers(req *http.Request) *http.Response {
    // Fluent query builder
    users := database.
        Table("users").
        Where("active", true).
        OrderBy("created_at", "desc").
        Limit(10).
        Get()

    return req.JSON(users)
}

func getUserWithPosts(req *http.Request) *http.Response {
    // ORM with eager loading
    var user User
    database.
        Model(&user).
        With("Posts.Comments").
        Find(req.Param("id"))

    return req.JSON(user)
}

Process Background Jobs

package jobs

import "github.com/sazzadh88/ignite/queue"

type SendWelcomeEmail struct {
    UserID int
}

func (j *SendWelcomeEmail) Handle() error {
    // Send email logic here
    return nil
}

// Dispatch the job
queue.Dispatch(&SendWelcomeEmail{UserID: 123})

// Chain jobs together
queue.
    Chain(
        &ProcessPayment{OrderID: 456},
        &SendReceipt{OrderID: 456},
        &NotifyWarehouse{OrderID: 456},
    ).
    Dispatch()

Batteries Included

Ignite comes with everything you need to build modern web applications:

  • Routing: Expressive routes, middleware, groups, resource routes, domain routing
  • Database: Query builder, ORM with relationships, migrations, transactions, seeders
  • Authentication: Guards (session, token), password hashing, API tokens, Gates, Policies
  • Validation: 50+ built-in rules, custom rules, Form Requests
  • Cache: Memory, Redis, file drivers with tags, locks, and atomic operations
  • Queue: Background jobs, workers, chains, batches, retries, rate limiting
  • Events: Event dispatcher, listeners, subscribers, async processing
  • Mail: Mailables, multiple transports (SMTP, SES, Mailgun), queueable
  • Notifications: Multi-channel notifications (mail, SMS, Slack, database)
  • Scheduling: Cron-style task scheduler with frequency helpers
  • HTTP Client: Fluent HTTP requests with retries, middleware, and macros
  • Broadcasting: WebSocket and SSE support for real-time features
  • Rate Limiting: Flexible rate limiters for APIs and routes
  • File Storage: Local and S3 storage with unified interface
