Routing

Ignite's routing system provides an expressive, elegant way to define your application's URL structure. Inspired by Laravel, it supports all modern routing patterns including RESTful resources, middleware, route groups, and more.

Basic Routing

The most basic routes accept a URI and a handler function:

package routes

import (
    "github.com/sazzadh88/ignite/http"
    "github.com/sazzadh88/ignite/routing"
)

func RegisterRoutes(router *routing.Router) {
    router.Get("/", func(req *http.Request) *http.Response {
        return req.View("welcome")
    })

    router.Post("/submit", func(req *http.Request) *http.Response {
        return req.JSON(map[string]string{"status": "success"})
    })
}

Available HTTP Methods

router.Get("/users", handler)
router.Post("/users", handler)
router.Put("/users/{id}", handler)
router.Patch("/users/{id}", handler)
router.Delete("/users/{id}", handler)
router.Options("/users", handler)

// Match multiple methods
router.Match([]string{"GET", "POST"}, "/form", handler)

// Match any method
router.Any("/webhook", handler)

Route Parameters

Capture dynamic segments of the URI using route parameters:

Required Parameters

router.Get("/users/{id}", func(req *http.Request) *http.Response {
    id := req.Param("id")
    return req.JSON(map[string]string{"user_id": id})
})

router.Get("/posts/{post}/comments/{comment}", func(req *http.Request) *http.Response {
    postID := req.Param("post")
    commentID := req.Param("comment")
    // ...
})

Optional Parameters

router.Get("/users/{id?}", func(req *http.Request) *http.Response {
    id := req.Param("id")
    if id == "" {
        // List all users
    } else {
        // Show specific user
    }
})

Parameter Constraints

// Only match numeric IDs
router.Get("/users/{id}", handler).Where("id", "[0-9]+")

// Multiple constraints
router.Get("/posts/{slug}/page/{page}", handler).
    Where("slug", "[a-z-]+").
    Where("page", "[0-9]+")

// Using whereNumber and whereAlpha helpers
router.Get("/users/{id}", handler).WhereNumber("id")
router.Get("/tags/{tag}", handler).WhereAlpha("tag")

Named Routes

Named routes allow you to generate URLs or redirects easily:

router.Get("/users/{id}/profile", handler).Name("user.profile")

// Generate URL
url := routing.Route("user.profile", map[string]string{"id": "123"})
// Returns: /users/123/profile

// Redirect to named route
return req.RedirectToRoute("user.profile", map[string]string{"id": "123"})

Route Groups

Route groups allow you to share attributes across multiple routes:

Middleware

router.Group(func(r *routing.Router) {
    r.Middleware(middleware.Auth())

    r.Get("/dashboard", dashboardHandler)
    r.Get("/profile", profileHandler)
    r.Post("/settings", settingsHandler)
})

Prefix

router.Prefix("/admin").Group(func(r *routing.Router) {
    r.Get("/users", adminUsersHandler)      // /admin/users
    r.Get("/posts", adminPostsHandler)      // /admin/posts
    r.Get("/settings", adminSettingsHandler) // /admin/settings
})

Combining Attributes

router.
    Prefix("/api/v1").
    Middleware(middleware.Auth(), middleware.RateLimit()).
    Group(func(r *routing.Router) {
        r.Get("/users", apiUsersHandler)
        r.Get("/posts", apiPostsHandler)
    })

Named Route Groups

router.
    Prefix("/api").
    Name("api.").
    Group(func(r *routing.Router) {
        r.Get("/users", handler).Name("users") // Route name: api.users
        r.Get("/posts", handler).Name("posts") // Route name: api.posts
    })

Resource Routes

Quickly create RESTful resource routes with a single line:

router.Resource("/posts", &PostController{})

This single line registers all of these routes:

Method URI Action Route Name
GET /posts Index posts.index
GET /posts/create Create posts.create
POST /posts Store posts.store
GET /posts/{id} Show posts.show
GET /posts/{id}/edit Edit posts.edit
PUT/PATCH /posts/{id} Update posts.update
DELETE /posts/{id} Destroy posts.destroy

API Resources

For APIs, you can exclude the create and edit routes:

router.ApiResource("/posts", &PostController{})

Partial Resources

// Only include specific actions
router.Resource("/posts", &PostController{}).Only("index", "show")

// Exclude specific actions
router.Resource("/posts", &PostController{}).Except("destroy")

Nested Resources

router.Resource("/posts.comments", &CommentController{})
// GET /posts/{post}/comments
// POST /posts/{post}/comments
// GET /posts/{post}/comments/{comment}
// etc.

Domain Routing

Route requests based on the subdomain:

router.Domain("api.example.com").Group(func(r *routing.Router) {
    r.Get("/users", apiUsersHandler)
})

// With dynamic subdomains
router.Domain("{account}.example.com").Group(func(r *routing.Router) {
    r.Get("/dashboard", func(req *http.Request) *http.Response {
        account := req.Param("account")
        // Load tenant-specific data
    })
})

Route Middleware

Assign middleware to routes or route groups:

Single Route

router.
    Get("/admin", adminHandler).
    Middleware(middleware.Auth(), middleware.Admin())

Route Group

router.Group(func(r *routing.Router) {
    r.Middleware(middleware.Auth())
    r.Get("/dashboard", dashboardHandler)
})

Global Middleware

// In your application bootstrap
router.Use(
    middleware.Logger(),
    middleware.CORS(),
    middleware.RateLimiter(),
)

Creating Custom Middleware

package middleware

import "github.com/sazzadh88/ignite/http"

func CheckAge() http.Middleware {
    return func(next http.Handler) http.Handler {
        return func(req *http.Request) *http.Response {
            age := req.Input("age")

            if age < "18" {
                return req.JSON(map[string]string{
                    "error": "You must be 18 or older",
                }).Status(403)
            }

            return next(req)
        }
    }
}

Rate Limiting

Protect your routes with rate limiting:

import "github.com/sazzadh88/ignite/ratelimit"

// 60 requests per minute
router.
    Get("/api/users", handler).
    Middleware(ratelimit.Throttle(60, 1))

// Custom rate limiter
router.Group(func(r *routing.Router) {
    r.Middleware(ratelimit.For("api").
        By(func(req *http.Request) string {
            return req.User().ID // Rate limit per user
        }).
        Limit(100).
        PerMinute())

    r.Get("/data", dataHandler)
})

Fallback Routes

Define a route to handle 404 errors:

router.Fallback(func(req *http.Request) *http.Response {
    return req.View("errors.404").Status(404)
})

Route Caching

In production, cache your routes for better performance:

ignite route:cache

Clear the route cache:

ignite route:clear

Route Inspection

List all registered routes:

ignite route:list

This displays a table of all routes with their methods, URIs, names, and handlers.
